# K2 Horizon Ascent Challenge — Submissions

Submit your quest work here with a pull request, then paste the pull request link into the quest on the challenge site.

You can also keep your work in your own **public** GitHub repository and paste that repository link instead. Either way works.

## How to submit

1. Click **Fork** (top right) to make your own copy of this repository.
2. In your copy, add a folder for your work:
   `submissions/<your-github-username>/<quest-name>/`
   For example: `submissions/ada-lovelace/ship-a-tiny-evaluator/`
3. Put your files in that folder, with a `README.md` explaining:
   - what you built or tried,
   - how to run it (if it runs),
   - your results and any limitations.
4. Click **Contribute → Open pull request**. Use the quest name and your name as the title.
5. Copy the pull request link (it looks like `https://github.com/yakilan/k2-ascent-challenge/pull/12`) and paste it into the quest's evidence box on the challenge site.

## Rules

- One quest per pull request. Only change files inside your own folder.
- Text and code only — keep each file under 32 KB. Large files, images and binaries are not reviewed.
- **Never commit API keys, passwords or other secrets.** Everything here is public.
- Don't change your pull request after submitting on the site; the review looks at it as it was when checked. If you need to update it, resubmit on the site afterwards.
- Security findings that should stay confidential do not belong here. Use the private safety report on the challenge site.
